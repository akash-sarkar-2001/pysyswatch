# Security Policy

## Supported Versions
Only the latest major release of PySysWatch receives security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability
Please treat PySysWatch as security-sensitive infrastructure software. Do NOT open a public GitHub issue for vulnerabilities.

Instead, email security@yourdomain.com with details of the vulnerability, steps to reproduce, and your environment (Docker, systemd, OS version). We will acknowledge your report within 48 hours.
